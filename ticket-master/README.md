# Ticket Master — English Speaking Game (Grade 7)

An interactive English game for the "Travel and transport" topic: students buy a train ticket from Almaty to Astana and talk to a ticket seller.

**Play:** https://nvrrmindd.github.io/Web-Dev/ticket-master/

Four stations, 100 points:
1. Ticket words: vocabulary quiz (20)
2. Build the dialogue: put the lines in order (20)
3. Grammar check: fill the gaps (20)
4. Speaking role-play: answer in your own words, by voice or typing (40)

One self-contained `index.html`, no build step. Text-to-speech on every line; speech recognition works in Chrome.
